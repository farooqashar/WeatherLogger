# WeatherLogger

A lightweight script to log weather data.

## Features
- Fetches weather from `wttr.in`.
- Creates a new log file for each month (e.g., `weather_log_2026_05.txt`).
- Simple and dependency-light.

## Setup
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the script:
   ```bash
   python3 scripts/log_weather.py
   ```
